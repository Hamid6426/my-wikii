# 25 - HTML Tools

| Tool           | What it does                                                                  |
| -------------- | ----------------------------------------------------------------------------- |
| HTML validator | Checks your HTML for syntax errors. Try the W3C validator at validator.w3.org |
| DOM inspector  | Shows and edits the live structure of a page                                  |
| DevTools       | Built into the browser. Debug, profile and analyze a page                     |

---

## Open DevTools

| Action             | Keys                         |
| ------------------ | ---------------------------- |
| Open DevTools      | `F12` or `Ctrl+Shift+I`      |
| Inspect an element | Right click it, then Inspect |

The **Elements** tab shows the DOM (Document Object Model), the page as the browser built it. It can differ from your file, because the browser fixes mistakes in the HTML.

---

## Gotchas

- Edits in DevTools are lost on reload. Copy the change back into your file
