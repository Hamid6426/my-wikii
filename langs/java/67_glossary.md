# 67 - Glossary

Short definitions of terms used across these lessons, in alphabetical order within each group. Each entry points to the lesson that teaches it.

## A to C

| Term              | Meaning                                                                                                             | Lesson                                                                          |
| ----------------- | ------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| Abstract class    | A class that cannot be created directly and can leave methods for subclasses to fill in                             | [Interfaces and Abstract Classes](32_interfaces_and_abstract_classes.md)        |
| Access modifier   | A keyword (`public`, `protected`, `private`, or none) that controls who can use a member                            | [Classes and Objects](26_classes_and_objects.md)                                |
| Annotation        | Metadata attached to code with `@Name`, such as `@Override`                                                         | [Annotations and Reflection](55_annotations_and_reflection.md)                  |
| Anonymous class   | A class with no name, written inline to implement an interface or extend a class                                    | [Nested, Inner and Anonymous Classes](28_nested_inner_and_anonymous_classes.md) |
| AOT cache         | A file of preloaded classes from a training run that makes later starts faster (Java 24+)                           | [Packaging and Deployment](63_packaging_and_deployment.md)                      |
| API               | Application Programming Interface: the public types and methods one piece of code offers to another                 | [Interfaces and Abstract Classes](32_interfaces_and_abstract_classes.md)        |
| Argument          | The actual value you pass to a method (the method declares a parameter)                                             | [Methods](16_methods.md)                                                        |
| Array             | A fixed-size, indexed list of values of one type, such as `int[]`                                                   | [Arrays](18_arrays.md)                                                          |
| Assertion         | A check in a test that fails the test when it is false, such as `assertEquals`                                      | [Testing](59_testing.md)                                                        |
| Autoboxing        | The compiler wrapping a primitive in its wrapper class automatically, such as `int` to `Integer`                    | [Object and Wrapper Classes](23_object_and_wrapper_classes.md)                  |
| AutoCloseable     | An interface with a `close()` method, so try-with-resources can release the object                                  | [AutoCloseable and try-with-resources](33_autocloseable.md)                     |
| Benchmark         | A repeatable measurement of how fast code runs                                                                      | [Performance Basics](61_performance_basics.md)                                  |
| Boxing            | Wrapping a primitive value in an object, such as `Integer`                                                          | [Object and Wrapper Classes](23_object_and_wrapper_classes.md)                  |
| Break             | Ends the nearest loop or `switch` right away                                                                        | [Loops](15_loops.md)                                                            |
| Breakpoint        | A marker that pauses the program at a line so you can inspect it                                                    | [Debugging](43_debugging.md)                                                    |
| Buffer            | A block of memory that holds data on its way between two places                                                     | [File I/O: Streams](47_file_io_streams.md)                                      |
| Build tool        | A program that compiles, tests, and packages a project and downloads libraries: Maven or Gradle                     | [Projects and Build Tools](02_projects_and_build_tools.md)                      |
| Bytecode          | The portable instructions in `.class` files that the JVM runs                                                       | [JVM Internals](35_jvm_internals.md)                                            |
| Cast              | Converting a value to another type by writing the type in parentheses, such as `(int) x`                            | [Type Conversion](10_type_conversion.md)                                        |
| Catch block       | The block after `try` that handles a thrown exception of one type                                                   | [Error Handling](42_error_handling.md)                                          |
| Checked exception | An exception the compiler forces you to catch or declare with `throws`                                              | [Error Handling](42_error_handling.md)                                          |
| Class             | A blueprint for objects: fields for data and methods for behavior                                                   | [Classes and Objects](26_classes_and_objects.md)                                |
| Class loader      | The object that reads `.class` files into the JVM: bootstrap, platform, or application                              | [JVM Internals](35_jvm_internals.md)                                            |
| Class path        | The list of folders and jars where the JVM looks for classes                                                        | [Packages and Imports](06_packages_and_imports.md)                              |
| Closure           | A lambda that uses variables from the method around it. Those variables must be effectively final                   | [Lambdas and Functional Interfaces](39_lambdas_and_functional_interfaces.md)    |
| Collection        | An object that holds a group of items, such as a `List`, `Set`, or `Map`                                            | [Collections](36_collections.md)                                                |
| Comparable        | An interface that gives a class its natural order through `compareTo`                                               | [equals, hashCode and Comparable](29_equals_hashcode_and_comparable.md)         |
| Comparator        | An object that defines an order for items, separate from the item class                                             | [equals, hashCode and Comparable](29_equals_hashcode_and_comparable.md)         |
| Compile time      | The moment `javac` builds your code. Errors found here appear before the program runs. The other moment is run time | [Getting Started](01_getting_started.md)                                        |
| Compiler          | Turns `.java` source into `.class` bytecode. The JDK one is `javac`                                                 | [Getting Started](01_getting_started.md)                                        |
| CompletableFuture | An object that stands for a result that will arrive later, with methods to chain more work                          | [CompletableFuture and Async Code](51_completablefuture_and_async.md)           |
| Composition root  | The one place, usually `main`, that creates the real objects and wires them together                                | [Dependency Injection](56_dependency_injection.md)                              |
| Connection        | One open session with a database in JDBC                                                                            | [JDBC](50_jdbc.md)                                                              |
| Constant          | A `static final` value that never changes, named in `UPPER_SNAKE_CASE`                                              | [Variables and Constants](07_variables_and_constants.md)                        |
| Constructor       | Special method that sets up a new object                                                                            | [Classes and Objects](26_classes_and_objects.md)                                |
| Continue          | Skips the rest of this loop pass and starts the next one                                                            | [Loops](15_loops.md)                                                            |

| Gradle                 | A build tool configured with a Kotlin or Groovy script                                                                      | [Projects and Build Tools](02_projects_and_build_tools.md)                      |
| Hash                   | A fixed-size fingerprint of data that cannot be reversed                                                                    | [Security Basics](62_security_basics.md)                                        |

| Immutable              | Cannot change after it is created                                                                                           | [Records and Equality](25_records_and_equality.md)                              |
| Import                 | A line that lets you use a class by its short name instead of its full package name                                         | [Packages and Imports](06_packages_and_imports.md)                              |
| Inheritance            | A class taking the fields and methods of a parent class with `extends`                                                      | [Inheritance](30_inheritance.md)                                                |
| Injection              | An attack where user input becomes part of a command, such as SQL injection                                                 | [Security Basics](62_security_basics.md)                                        |

| Interface              | A contract: a list of methods a class promises to have                                                                      | [Interfaces and Abstract Classes](32_interfaces_and_abstract_classes.md)        |
| Iterator               | An object that walks through a collection one item at a time with `hasNext` and `next`                                      | [Iterators and Iterable](38_iterators.md)                                       |
