# Desktop interfaces

Tags: `containers` `desktop` `desktop-interfaces` `gui` `oci`

Local developer UX for containers — GUIs and lightweight VM wrappers. These compete mainly with **Docker Desktop**, not with [containerd](../runtimes/containerd/README.md) in production.

> **Licensing reminder:** Docker Desktop has commercial-use rules for larger orgs — see [Docker platforms](../docker/platforms/README.md). Alternatives below are commonly evaluated for license, RAM, or Kubernetes-on-laptop needs.
