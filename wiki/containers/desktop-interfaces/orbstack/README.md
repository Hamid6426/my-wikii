# OrbStack

Tags: `containers` `desktop` `desktop-interfaces` `macos` `oci` `orbstack` `vm`

Commercial, macOS-focused Docker-compatible environment known for **fast startup** and relatively **low RAM** versus Docker Desktop. Closed source.

Evaluate against [Docker on macOS](../../docker/platforms/macos/README.md), [Colima](../colima/README.md), and [Podman Desktop](../../podman/podman-desktop/README.md) for license and workflow fit.
