# Rancher Desktop

Tags: `containers` `desktop` `desktop-interfaces` `kubernetes` `oci` `rancher-desktop`

Open-source desktop app (SUSE/Rancher) for local containers and **Kubernetes**. Lets you choose a container runtime backend (**containerd** or **dockerd**-compatible paths depending on version/settings).

Good when you want **local K8s + containers** without Docker Desktop. Heavier than Colima; more batteries than raw Podman CLI.
