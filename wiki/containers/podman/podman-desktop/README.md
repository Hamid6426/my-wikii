# Podman Desktop

Tags: `containers` `desktop` `gui` `oci` `podman` `podman-desktop`

GUI for Podman (and related tooling) from the Podman/Red Hat ecosystem. Open source alternative to Docker Desktop for browsing images, containers, and compose-style apps.

Install from [podman-desktop.io](https://podman-desktop.io/) or your platform's package sources. On Linux it talks to a local Podman engine; on Mac/Windows it manages a Linux VM/machine similar in spirit to other desktop wrappers.

> Licensing and feature sets change — verify current docs if you are replacing Docker Desktop for org policy reasons.
