# CRI-O

Tags: `containers` `cri` `cri-o` `kubernetes` `oci` `runtime` `runtimes`

**CRI-O** is a Kubernetes CRI implementation for running OCI containers — built for kubelet, not as a general Docker Desktop replacement.

Choose CRI-O when operating **Kubernetes nodes** that standardize on it (OpenShift historically, some kubeadm/cluster choices). For laptop app containers, prefer [Podman](../../podman/README.md) or [Docker](../../docker/README.md).
