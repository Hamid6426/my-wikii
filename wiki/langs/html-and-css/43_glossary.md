# 43 - Glossary

| Term              | Meaning                                                    |
| ----------------- | ---------------------------------------------------------- |
| Element           | A tag pair and its content, such as `<p>text</p>`          |
| Tag               | The `<p>` or `</p>` part                                   |
| Attribute         | Extra info in an opening tag, such as `href="..."`         |
| Void element      | An element with no content or closing tag, such as `img`   |
| Boolean attribute | Present means true, absent means false                     |
| Entity            | A code for a character, such as `&lt;`                     |
| Semantic          | Describes meaning, not looks                               |
| DOM               | The page as the browser holds it in memory                 |
| DOCTYPE           | The first line. Tells the browser to use modern HTML       |
| UTF-8             | The character encoding for all languages                   |
| Metadata          | Information about the page, kept in `head`                 |
| Open Graph        | `meta` tags that control social media previews             |
| SEO               | Making a page easier to find in search engines             |
| Replaced element  | An element whose content comes from outside, such as `img` |
| Absolute URL      | A full address with protocol and domain                    |
| Relative path     | A location based on the current file                       |
| ISO 8601          | The standard date format `YYYY-MM-DDThh:mm:ss`             |
| CSS               | Cascading Style Sheets. Controls how HTML looks            |
| Selector          | The part of a rule that picks elements                     |
| Specificity       | The weight that decides which rule wins                    |
| Cascade           | The rules for resolving conflicting styles                 |
| Box model         | Content, padding, border and margin around every element   |
| Flexbox           | A one-direction layout system                              |
| Grid              | A two-direction layout system                              |
| Pseudo-class      | A state selector, such as `:hover`                         |
| Pseudo-element    | A part of an element, such as `::before`                   |
| Custom property   | A CSS variable, such as `--brand`                          |
| Media query       | A rule that applies only on certain screens or settings    |
| Breakpoint        | The screen width where the layout changes                  |
| Viewport          | The visible area of the page in the browser                |
| ARIA              | Attributes that add accessibility meaning                  |
