# HTML and CSS

Tags: `html-and-css` `langs`

Notes for learning HTML, the markup language for the structure and meaning of web pages, and CSS, the style language for layout, spacing, color and responsive design, in 43 short lessons. HTML is lessons 01 to 25 and CSS is 26 to 41. Start with [Getting Started](01_getting_started.md). The [Glossary](43_glossary.md) explains the terms.
