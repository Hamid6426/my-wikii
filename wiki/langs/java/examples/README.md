# Java Examples

Tags: `examples` `java` `langs`

Small runnable programs for the lessons in this folder. Each one is a single `.java` file.

## Naming

`NN-MM_name.java`: `NN` is the lesson number and `MM` is the example number within that lesson.

A lesson with no code has a one-line file `NN-00_no_examples.txt` that says so.

---

## Requirements

JDK 21 or newer. Check with `java -version`. See [Getting Started](../01_getting_started.md).

---

## Run an Example

From this folder, run the source file directly. No separate compile step is needed:

```bash
java 01-01_your_first_program.java
```

| Example needs         | How to run it                                          |
| --------------------- | ------------------------------------------------------ |
| Nothing extra         | `java NN-MM_name.java`                                 |
| Typed input           | Run it, then type and press Enter                      |
| Java 25 features      | Use JDK 25 (the example says so in its comments)       |
| Native access (34-01) | `java --enable-native-access=ALL-UNNAMED 34-01_*.java` |

Each example has a header comment with the lesson it belongs to, and the lesson shows the expected output.
