# Gentoo

Tags: `distro` `distros` `gentoo` `linux` `others` `portage` `source`

- **Role:** Source-based, extreme configurability (`emerge`, USE flags).
- **Strengths:** Compile-to-taste, deep understanding of the stack.
- **Trade-offs:** Time and maintenance cost; not for casual installs.
