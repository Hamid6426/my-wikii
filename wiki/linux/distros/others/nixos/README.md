# NixOS

Tags: `declarative` `distro` `distros` `linux` `nix` `nixos` `others`

- **Role:** Declarative OS; system config is code (`configuration.nix` / flakes).
- **Strengths:** Reproducible machines, atomic upgrades/rollbacks, huge nixpkgs.
- **Trade-offs:** Steep learning curve; different mental model than imperative distros.
