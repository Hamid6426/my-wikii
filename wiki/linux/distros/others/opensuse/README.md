# openSUSE / SUSE

Tags: `distro` `distros` `linux` `opensuse` `others` `rpm` `zypper`

- **Leap:** Fixed-release, closer to SLE.
- **Tumbleweed:** Rolling, tested with openQA.
- **Tools:** `zypper`, YaST; Btrfs + Snapper snapshots are a common selling point.
- **Enterprise twin:** SUSE Linux Enterprise (SLE).

```bash
sudo zypper refresh
sudo zypper update
sudo zypper install <package>
```
