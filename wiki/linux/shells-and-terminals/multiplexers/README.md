# Multiplexers

Tags: `cli` `linux` `multiplexer` `multiplexers` `shells-and-terminals`

A **terminal multiplexer** keeps shells alive across disconnects and provides panes/tabs **inside** one terminal window. It sits between the [terminal emulator](../terminals/README.md) and the [shell](../shells/README.md):

```
Terminal → tmux/Zellij → shell(s)
```

Useful with SSH, tiling WMs that don't want a heavy terminal-tab UI, and [Alacritty](../terminals/alacritty/README.md)-style minimal terminals.
