# Zellij

Tags: `cli` `linux` `multiplexer` `multiplexers` `shells-and-terminals` `zellij`

Modern multiplexer with a discoverable UI, floating panes, and built-in layouts. Often friendlier for newcomers than memorizing tmux keybinds.

```bash
zellij
zellij attach
```

Config under `~/.config/zellij/`. Features and defaults move faster than tmux — check upstream docs for your version.
