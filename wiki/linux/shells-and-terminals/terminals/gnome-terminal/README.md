# GNOME Terminal

Tags: `cli` `gnome-terminal` `gtk` `linux` `shells-and-terminals` `terminal` `terminals`

Default terminal emulator on many GNOME-based desktops. VTE-based, integrates with GNOME settings and theming.

## Role

- Everyday terminal for Ubuntu Desktop, Fedora Workstation, Debian GNOME
- Profiles for fonts, colors, custom shell commands
- Tabs and basic splits (depending on version / preferences)

## Quick facts

| Item    | Detail                                |
| ------- | ------------------------------------- |
| Package | `gnome-terminal`                      |
| Engine  | VTE                                   |
| Desktop | GNOME                                 |
| Config  | Preferences GUI; dconf under the hood |

## Notes

Solid default. If you want GPU rendering, ligatures-heavy setups, or image protocols, people often move to [Kitty](../kitty/README.md) / [Alacritty](../alacritty/README.md) / [WezTerm](../wezterm/README.md) while keeping the same [shell](../../shells/README.md).
