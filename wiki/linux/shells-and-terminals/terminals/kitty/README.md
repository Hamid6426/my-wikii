# Kitty

Tags: `cli` `gpu` `kitty` `linux` `shells-and-terminals` `terminal` `terminals`

GPU-accelerated terminal focused on keyboard control, performance, and features (images, tips, remote control). Configured via a text file.

## Role

- Popular "power user" terminal across DEs and WMs
- Great with tiling window managers (fast, scriptable)
- Config: `~/.config/kitty/kitty.conf`

## Quick facts

| Item      | Detail                                          |
| --------- | ----------------------------------------------- |
| Package   | `kitty`                                         |
| Rendering | GPU (OpenGL)                                    |
| Extras    | Kittens (icats, themes, ssh, …), remote control |

## Useful bits

```bash
kitty --version
# reload config with the keybind from kitty.conf (often Ctrl+Shift+F5)

```

Supports graphics protocols useful for image preview in the terminal. Steeper config-file learning curve than GNOME Terminal/Konsole GUIs.
