# Konsole

Tags: `cli` `kde` `konsole` `linux` `shells-and-terminals` `terminal` `terminals`

KDE's terminal emulator. Feature-rich: profiles, splits, SSH bookmarks, integration with Plasma/Dolphin.

## Role

- Default terminal on Plasma desktops (Kubuntu, Fedora KDE, etc.)
- Strong profile system (different fonts/shells per profile)
- Tabs and split views built in

## Quick facts

| Item    | Detail                                       |
| ------- | -------------------------------------------- |
| Package | `konsole`                                    |
| Desktop | KDE Plasma                                   |
| Config  | Konsole profiles + `~/.local/share/konsole/` |

## Notes

Good all-rounder if you already live in Plasma. Part of the KDE Applications set; theming follows your Plasma color scheme unless overridden.
