# WezTerm

Tags: `cli` `gpu` `linux` `shells-and-terminals` `terminal` `terminals` `wezterm`

GPU-accelerated terminal with panes, tabs, mux features, and **Lua** configuration. Aims to be powerful without needing a separate multiplexer for many workflows.

## Role

- All-in-one terminal for people who want splits + config-as-code
- Cross-platform; strong Linux support
- Config: `~/.config/wezterm/wezterm.lua`

## Quick facts

| Item            | Detail                                 |
| --------------- | -------------------------------------- |
| Package         | `wezterm`                              |
| Rendering       | GPU                                    |
| Config language | Lua                                    |
| Features        | Multiplexing, domains, rich key tables |

## Notes

More moving parts than Alacritty; more structured than ad-hoc Kitty configs for some users. Lua config is flexible but is a learning investment.
