# bspwm

Tags: `bspwm` `linux` `tiling` `window-managers` `wm` `x11`

Binary-space partitioning tiling window manager for X11. Windows split into a tree of containers; heavily scriptable via `bspc`. Usually paired with **sxhkd** for hotkeys.

## Feel

Minimal and programmable. Less "batteries included" than i3's default config story — you wire bar, keys, and rules yourself.

## Stack

- **Display:** X11
- **Type:** Tiling WM
- **Hotkeys:** typically sxhkd
- **Config:** `~/.config/bspwm/bspwmrc`
