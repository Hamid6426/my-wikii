# Hyprland

Tags: `hyprland` `linux` `tiling` `wayland` `window-managers` `wm`

Dynamic tiling Wayland compositor known for smooth animations and eye-candy defaults. Config-driven; large community dotfile ecosystem.

## Feel

Modern and flashy out of the box compared to stock i3/Sway. Still a compositor + your choice of bar/launcher — not a full DE.

## Stack

- **Display:** Wayland
- **Type:** Dynamic tiling compositor
- **X11 apps:** XWayland

## Notes

Follow Hyprland's own wiki for install (some distros package it; others need community repos). Config and feature velocity are high.
