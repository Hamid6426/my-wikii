# i3

Tags: `i3` `linux` `tiling` `window-managers` `wm` `x11`

Popular tiling window manager for X11. Keyboard-driven, config-file based (`~/.config/i3/config`), minimal by default — you add a status bar (i3bar/i3status/polybar), launcher, and compositor as needed.

## Feel

Tiling-first productivity. Steep at first if you expect a full DE; excellent once keybindings click.

## Stack

- **Display:** X11
- **Type:** Tiling WM (not a full DE)
- **Wayland cousin:** [Sway](../sway/README.md)

## Tips

- Start from the default config and edit gradually.
- Gaps, bar, and notifications usually come from extra packages.
