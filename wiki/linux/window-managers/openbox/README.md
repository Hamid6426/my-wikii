# Openbox

Tags: `linux` `openbox` `stacking` `window-managers` `wm` `x11`

Stacking (floating) window manager for X11. Light, stable, and a common foundation under lightweight desktops (especially LXQt-style setups) or standalone minimal sessions.

## Feel

Classic floating windows, menu, and rc.xml theming. Not tiling-first (tiling needs extras or another WM).

## Stack

- **Display:** X11
- **Type:** Stacking WM
- **Config:** `~/.config/openbox/` (`rc.xml`, `autostart`, menu)
- **Often under:** [LXQt](../../desktop-environments/lxqt/README.md) and other light spins
