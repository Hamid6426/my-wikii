# Sway

Tags: `linux` `sway` `tiling` `wayland` `window-managers` `wm`

i3-compatible tiling compositor for Wayland. Same mental model and largely the same config syntax as i3, on the modern display stack.

## Feel

i3 users feel at home. Prefer Sway when you want tiling on Wayland (fractional scaling, isolation, etc.).

## Stack

- **Display:** Wayland
- **Type:** Tiling compositor
- **X11 apps:** via XWayland
- **X11 cousin:** [i3](../i3/README.md)
